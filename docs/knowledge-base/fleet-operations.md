# Fleet operations

**Sidebar:** Season → **Fleet operations**

**What it's for:** season-wide bulk actions when you file for many entities at once — transmit, send summaries, invite clients, or request W-9s across a chosen set of payers, with honest previews so you always know exactly what an action will hit.

## The entity picker
Every fleet action runs against a **working list** of payers you build yourself:

- **Search to add** — type a company name and click to add it to the list.
- **"Add all …" quick-adds** — one click to add every payer in a given state, e.g. *Ready-to-transmit*, *Uninvited*, *Missing W-9*, *With accepted forms*. Each button shows a live count.
- Remove chips individually, or **Clear** to start over.

Nothing goes firm-wide silently — an action only touches the payers in your basket.

## Actions
Each action shows an **eligibility count** before you run it (how many payers/records actually qualify):

- **Transmit** — e-file the queued forms for the selected payers.
- **Summaries** — send each selected client a summary of what was filed.
- **Invite** — send client-entry invites to the selected (or uninvited) payers.
- **W-9** — request missing tax IDs across the selection.

## Dry-run, run, and retry
- Outbound/irreversible actions **confirm with the count** first.
- A **filing run** records per-item results. If some items fail, you can **retry just the failed ones** without re-running the successes.
- The **run history** drills into per-payer outcomes so you can see exactly what happened.

**Tips:**
- Changing the **Tax year** clears the working list (so you don't accidentally act on the wrong year).
- Use *Ready-to-transmit* to sweep everything staged, then *Retry failed* to mop up.
