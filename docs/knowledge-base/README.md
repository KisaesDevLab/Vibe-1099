# Vibe 1099 — Knowledge Base

Vibe 1099 is a self-hosted appliance for CPA firms to **prepare, deliver, and e-file 1099 forms** (NEC, MISC, INT, DIV). This knowledge base explains what each screen does and how to run a filing season end to end.

## Start here
- **[Overview](overview.md)** — what the app does, roles, trust zones, and core concepts.
- **[Getting started](getting-started.md)** — sign in, first-run setup, and the layout.
- **[Season workflow](season-workflow.md)** — the whole season from onboarding to acceptance, step by step.
